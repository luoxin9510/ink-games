# 10.6 回合战斗

**本节要点**
- 「回合战斗」规则包:三人小队(骑士、法师、牧师)对一群敌人,按速度轮流出手,像老式日式角色扮演游戏。用「新建游戏」选它,或者在 `game.md` 里写 `system: { path: "…/规则包/turn-battle", version: 1 }`。
- 剧本先用 `spawn("foe", "goblin")` 叫出敌人,再 `-> battle ->`。打完读 `battle_result`(`"won"` 赢 / `"lost"` 全倒下)和 `battle_round`(打了几回合)。
- 一个故事里可以打好几场。生命、法力、药水和中毒会带到下一场,除非剧本自己改。
- 轮到哪个队员,选项就是他能做的事:攻击某个敌人、用技能、防御、给伤得最重的人喝药水。轮到敌人时它自己行动,不用选。

## 讲解

一场战斗只要几行:

```ink
INCLUDE _engine.ink
~ spawn("foe", "wolf")
~ spawn("foe", "wolf")
~ spawn("foe", "goblin")
-> battle ->
{ battle_result == "lost":
    -> fallen
}
```

规则(详见 `规则包/turn-battle/说明.md`):

- **回合**:每回合所有站着的人各动一次,速度(`spd`)高的先动;速度一样时队员先动。回合结束时中毒的人 −2 生命,状态的回合数减一。
- **伤害**:攻击 + 2d6 − 4 − 对方防御,至少 1;2d6 掷出 11 或 12 是暴击,再 +2。
- **技能**花法力:
  - 骑士**盾击**,2 法力:打一下,再让对方晕一次行动。
  - 法师**火球**,3 法力:每个敌人 2d6−3。
  - 牧师**治疗**,2 法力:一名队员 +2d6,同时解毒。
- **防御**:防御 +3,到自己下次行动为止。

两场之间想让队伍歇一歇,就自己写个函数,用 `nth_one("party", k)` 挨个改站着的人:

```ink
=== function rest(k) ===
~ temp who = nth_one("party", k)
{ who != "":
    ~ set_stat(who, "mp", stat(who, "mp_max"))
    ~ set_stat(who, "hp", MIN(stat(who, "hp") + 4, stat(who, "hp_max")))
    ~ rest(k + 1)
}
```

战斗里不会只给一个选项,所以 `check-ink --all` 走不完所有分支,会停在 `--max-steps`。量平衡要用 `--random 300`。

## 示例

`10.6 示例/`:翻山口。先打两只灰狼和一个地精;歇一夜后,法力回满、生命 +4;再选冲过桥打巨魔和萨满,还是绕远路(少一瓶药水)。按固定策略打,两场都赢大约 67%。

## 练习

1. 在 `game.md` 里换一支小队(`party:`),比如两个骑士一个牧师,看胜率怎么变。
2. 加一种自己的敌人:写一个 id 为 `foe` 的种类。同 id 的种类会整个替换,所以要把包里的模板也抄过来。
3. 用 `check-ink --random 300` 比较"冲过去"和"绕远路"各自的结局分布。
