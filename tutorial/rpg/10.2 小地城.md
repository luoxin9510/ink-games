# 10.2 小地城

**本节要点**
- 把**队伍**(`party`)、**敌人**(`kinds`)和**表里刷怪**(`spawn_from`)拼起来,就是一个能打的小地城。战斗规则全写在剧本里,引擎只管存数、掷骰、画卡片。
- 有 `kinds:` 时,队员的 id 也是实体 id:`stat("miner", "life")`、`add_stat(victim, "life", -2)`、`name_of("hound")`,和怪物一样写。
- `pick_one("party", "random")` 挑一个还站着的队员,`alive("party")` 数还站着几个。"每只怪咬一个随机的人"不用写一长串 `if`。
- 一个递归函数就能让每只怪轮流行动:`nth_one("foe", k)` 取第 k 只,做完再调自己处理 k + 1。

## 讲解

```ink
=== function foes_bite(k) ===
{ k > alive("foe") || alive("party") == 0:
    ~ return
}
~ temp biter = nth_one("foe", k)
~ temp victim = pick_one("party", "random")
~ add_stat(victim, "life", 0 - stat(biter, "bite"))
~ foes_bite(k + 1)
```

- 打的时候 `pick_one("foe", "lowest:life")` 选最弱的那只当目标,选项上写它的名字。
- 表的一行可以只是文字(空岔道),可以有 `id` 让剧本认出来(盐脉,加盐),也可以 `spawn` 怪物,还能用 `stats` 改它的属性(第 6 行的"老盐虫"是一条加强过的盐虫)。
- 盐王不走表,`spawn("foe", "king")` 直接刷出来。
- 平衡用 `check-ink --random 300` 看:每种怪来了多少、平均活几步、多少局全军覆没。

## 示例

`10.2 示例/`:旧盐矿。往下走五层,每层掷「坑道」表;打完可以继续往下,也可以带着盐上去。

## 练习

1. 给学徒加一个"包扎"选项:给 `pick_one("party", "lowest:life")` 加 2 点生命,一层只能用一次。
2. 让猎犬打蝙蝠时伤害加倍(提示:实体的模板可以从 id 看出来,也可以给怪加一个 `flying` 属性)。
3. 用 `check-ink --random 300` 调盐王的生命,让打到底的队伍大约一半能赢。
