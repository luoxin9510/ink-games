# 10.3 用规则包

**本节要点**
- **规则包**是一个文件夹,装着一套现成的规则:`system.md`(队伍、怪物、表、资源)和 `rules.ink`(战斗、搜房间这些流程)。用包做游戏,剧本只写故事,不写战斗代码。
- 命令「新建游戏(选规则包或模板)」:选「地城爬行」,再填一个文件夹名。插件把包装进 `规则包/dungeon-crawl/`(已经有了就不动),把包里的模板复制到新文件夹,生成引擎,打开面板。
- 游戏的 `game.md` 用 `system:` 指向包:`system: { path: "../../规则包/dungeon-crawl", version: 1 }`。路径从游戏的文件夹算起;`version` 是你写游戏时用的大版本,包升级到 2.x 时面板会提醒。
- 想改包里的东西,在自己的 `game.md` 里写**同 id 的条目**,它会替换包里的那一条;没写的照用包的。`party:` 这种不是列表的,整个替换。包本身不用改。

## 讲解

`game.md` 只写和包不一样的地方:

```yaml
system: { path: "../../../规则包/dungeon-crawl", version: 1 }
resources:
  - { id: torches, name: { zh: 火把, en: Torches }, min: 0, max: 12, initial: 4 }   # 只换火把这一条
party:   # 整支队伍换掉
  members:
    - { id: elder, name: { zh: 大哥, en: Eldest }, stats: { life: 7, life_max: 7, might: 2, guard: 1 } }
    …
```

剧本只有开头和结尾:

```ink
INCLUDE _engine.ink
~ crawl_rooms = 5
三兄妹下去了。
-> crawl ->
{ crawl_result:
- "won":  督军倒下了。
- "left": 走到第 {depth} 间,他们回头了。
- else:   火把灭了。
}
```

- `-> crawl ->` 是包里的一个隧道段落:一间一间走、掷房间表、打怪、最后一间打督军。回来以后读 `crawl_result`(`"won"` 赢了 / `"left"` 回头了 / `"fallen"` 全倒了)和 `depth`(走到第几间)。
- 生成的 `_engine.ink` 第二行是 `INCLUDE ../../../规则包/dungeon-crawl/rules.ink`。改了包或者 `game.md`,面板会提示引擎过期,运行「生成游戏引擎 ink」就好。
- 包的规则和可以改的地方写在 `规则包/dungeon-crawl/说明.md`。

## 示例

`10.3 示例/`:三兄妹拿着父亲的地图下地城。用的是地城爬行包,只换了队伍(三个人)和火把(4 支),地城 5 间。

## 练习

1. 用「新建游戏」从零做一个地城爬行游戏,开头和结尾换成你自己的故事。
2. 在 `game.md` 里加一条 `kinds:`,id 写 `foe`,复制包里的怪物再加一种自己的(注意:同 id 的种类是整个替换,所以包里原有的模板也要抄过来)。
3. 用 `check-ink --random 300` 看看只带 4 支火把以后,全军覆没的比例变了多少。
