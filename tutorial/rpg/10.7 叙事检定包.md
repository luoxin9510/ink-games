# 10.7 叙事检定包

**本节要点**
- 「叙事检定」规则包是从宿舍恐怖游戏《302》的规则里整理出来的,适合以剧情为主的游戏。包里有:
  - 2d6 + 技能对难度的检定,难度六档;
  - 五种会说话的技能;
  - 恐惧和体力两条血条;
  - 同伴的恐惧和信任;
  - 一条恐惧修正:恐惧每满 25,理智 −1;
  - `clamp()` 函数。
- 游戏只写自己的东西:角色、多出来的资源、物品,或者给某个技能换一个声音。写同 id 的条目,就会替换包里的那一条。
- 《302》本身就是这么用的。换成这个包以后,`check-ink` 的结果和换之前逐字相同。

## 讲解

```yaml
system: { path: "../../../规则包/narrative-check", version: 1 }
skills:   # 只换洞察力的声音
  - { id: insight, name: { zh: 洞察力, en: Insight }, voice: { stance: { zh: 书架在动。, en: "The shelves moved." }, color: "#b07cd8" } }
resources:   # 加一种资源,恐惧和体力还是包里的
  - { id: candle, name: { zh: 蜡烛, en: Candle }, min: 0, max: 3, initial: 3 }
characters:
  - { id: me, … }
  - { id: zhou, playable: false, …, companion: { fear: 40, trust: 40 } }
```

剧本和第七章一样写检定和心声:

```ink
* [数一数走过了几排书架 #check:insight:normal]
    { check("insight", 10) >= 3:
        十二排。可是这一层只有十排。
    - else:
        数到第九排你就乱了。
        ~ fear += 25
        ~ fear_zhou = clamp(fear_zhou + 15, 0, 100)
    }
```

- `check("技能", 数字)` 得到 0–4 档,3 及以上算成功。
- 失败要改变点什么,比如一个变量或者之后能选的选项;`check-ink --all` 会对什么都没改变的失败给出警告。
- 同伴的变量是 `fear_<id>` 和 `trust_<id>`。改它们时用包里的 `clamp` 限制在 0–100,因为引擎要等这一步结束才把超出的值拉回来。

## 示例

`10.7 示例/`:停电的图书馆。你和阿周举着三根蜡烛找出口。数书架是洞察力检定,数对了会多出一条路;陪阿周说话是魅力检定,会改变阿周的恐惧和信任;撞门是力量检定,阿周的信任够高时也能撞开。

## 练习

1. 给理智换一个声音,再加一个同伴。
2. 写一个 `scare(c, d)` 函数,按同伴的 id 分支改 `fear_<id>`(参考《302》的 `main.ink`;包不知道同伴叫什么,所以这种函数留在游戏里)。
3. 写 `modifiers: []` 关掉恐惧修正,用 `check-ink --random 300` 看撞门的成功率变了没有。
