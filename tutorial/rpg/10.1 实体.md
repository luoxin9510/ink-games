# 10.1 实体

**本节要点**
- `game.md` 里的 `kinds:` 声明一类**会冒出来、会被消灭的东西**:敌人、召唤物、路人。每类有属性(写法同小队的 `stats`)和若干模板(起始属性)。
- 剧本用 `spawn("foe", "rat")` 刷出一只,返回它的 id;`stat` / `set_stat` / `add_stat` 读写属性;`despawn` 移走;`alive("foe")` 数还剩几只。
- 写了 `remove: life`,生命被扣到 0 就自动移走;只想画成倒下(变灰)就写 `down: life`。
- `pick_one("foe", 挑法)` 挑一只:`random`(走这一局的骰子,会进掷骰记录)、`first`、`last`、`lowest:life`、`highest:attack`;`nth_one("foe", 2)` 取第二只;`name_of(id)` 是它在面板上的名字(同模板有几只时自动编号:老鼠 1、老鼠 2)。
- 面板在选项上方画出场上的实体,每类一行卡片,可以折叠;导出的网页列在状态栏里。回退、存档、换语言重放都照常。
- 随机表的一行可以写 `spawn: 模板`(还可以写 `count: 2` 或 `count: d3`、`stats: { life: 6 }`),`~ temp r = spawn_from("表")` 掷表并刷出那一行,返回掷出的点数。
- 有 `kinds:` 时,小队成员也走同一套函数:`stat("m1", "life")`、`add_stat("m1", "life", -1)`、`name_of("m1")`;`alive("party")`、`pick_one("party", "random")` 只算站着的成员(在场、没倒下)。怪物"随机咬一个英雄"就这么写。
- `check-ink --random` 按种类统计:每种模板来了几只、几只被打掉(平均活了几步)、结束时还剩几只、最多同时几只;属性被推过上限会给警告。

## 讲解

```yaml
kinds:
  - id: foe
    name: { zh: 敌人, en: Foes }
    stats:
      - { id: life, name: { zh: 生命, en: Life }, max: life_max }
      - { id: life_max, hidden: true }
      - { id: attack, name: { zh: 攻击, en: Attack } }
    remove: life
    templates:
      - { id: goblin, name: { zh: 哥布林, en: Goblin }, stats: { life: 2, life_max: 2, attack: 1 } }
```

```ink
~ temp g = spawn("foe", "goblin")
~ temp t = pick_one("foe", "lowest:life")
~ add_stat(t, "life", -1)
{ alive("foe") == 0: -> won }
```

- 实体都存在 ink 变量里(`VAR foe` 是一串文字,`VAR foe_n` 是编号计数),所以和别的状态一样跟着回退和存档走,不用自己管。
- id 是模板名、下划线加编号(`goblin_1`、`goblin_2`、`orc_3`),只当把手用;所以模板 id 在所有种类之间不能重名;给玩家看的名字用 `name_of`。
- 没有引擎(直接用普通 ink 跑)时什么也刷不出来,`alive` 是 0:剧本照样能编译、能走完。
- 用中文 ink 名字(`ink: zh`)时这些函数叫 生成/属性/设属性/加属性/移除/剩几个/挑一个/第几个/名字。
- 改了 `kinds:` 要运行「生成游戏引擎 ink」。

### 从表里刷怪

```yaml
tables:
  - id: lair
    rows:
      - { range: 1-3, zh: 两三只哥布林, en: some goblins, spawn: goblin, count: d2+1 }
      - { range: 4-6, zh: 一只兽人头目, en: an orc boss, spawn: orc, stats: { life: 8, life_max: 8 } }
```

```ink
~ temp r = spawn_from("lair")
冒出来{table_text("lair", r)}。
```

`count` 是骰子公式时走这一局的骰子,会出现在掷骰记录里。

## 示例

`10.1 示例/`:地窖里的老鼠。每轮用 `spawn_from` 从「地窖」表刷出一只老鼠、两只老鼠或一只大老鼠;打最弱的那只(力气检定),活着的每只咬你一口,第二轮还会再冒出一批。打光或者体力耗尽就结束。

## 练习

1. 加一个模板 `rat_king`(生命 5,咬 2),只在地窖表掷到 6 时出来。
2. 把 `remove: life` 改成 `down: life`,看倒下的老鼠在面板上怎么显示;想想 `alive` 这时该怎么数(提示:倒下的也还在场上)。
3. 让玩家选打哪一只:用 `nth_one` 给每只活着的老鼠各出一个选项。
