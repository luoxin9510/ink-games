# 10.5 成长和战役

**本节要点**
- **等级**:`levels: { resource: xp, at: [0, 4, 10] }`,`at` 写每一级需要多少经验(第一项是 1 级)。剧本里 `level` 是当前等级,`next_level_at()` 是下一级要的经验(到顶是 0),`level_up_ready()` 告诉你能不能升,`level_up()` 升一级。
- **升级给什么由剧本决定**:加属性、给一个**天赋**。天赋就是普通的物品(带 `modifiers`,不写 `slot`),带着就加值。状态栏在能升级时亮一个"可以升级"。
- **角色卡**:剧本里某一行末尾写 `#sheet`,玩到这一行时(点了选项之后第一次出现),面板把主角写成一篇笔记,放在 `game.md` 的 `sheets:` 指定的文件夹(相对于这个游戏的文件夹)。笔记的 frontmatter 就是 `characters` 的写法:技能、物品、装备、数量、等级、资源、状态;正文是这一行的文字,每次冒险加一段。也可以用命令「保存角色卡」。
- **下一次冒险**写 `characters: { from: ../角色 }`:可选的角色就是那个文件夹里的角色卡。营地也是一个普通的游戏,读进角色卡、休息升级,再写回去。

## 讲解

```yaml
# 冒险一的 game.md
system: ../规则
characters:
  - { id: lan, name: { zh: 阿岚, en: Lan }, skills: { might: 1, wits: 1 }, items: [sword], counts: { herb: 1 } }
sheets: ../角色

# 营地和冒险二的 game.md
system: ../规则
characters: { from: ../角色 }
sheets: ../角色
```

```ink
+ {level_up_ready()} [升级:天赋·勇猛(力气 +1)]
    ~ level_up()
    ~ give(brave, 1)
    -> camp
…
天亮了,阿岚 {level} 级,背着行装上路。 #sheet
```

- 三个故事的规则相同,所以放进一个小规则包 `规则/`(10.3 讲过),每个 `game.md` 只写和别人不一样的地方。
- 角色卡写的是**当时的样子**:生命、经验、金币、带着的东西、装备着的东西(`equipped`)、身上的状态(这里的"受伤"要到营地睡一觉才好)。
- 角色卡是普通笔记,可以手改:想给阿岚多一把草药,改 `counts` 就行。改了以后重新生成引擎(面板会提示);已经在玩的那一局不受影响,R1b 的旧版本机制会留着它。
- 网页导出不写角色卡(网页里没有 vault)。

## 示例

`10.5 示例/`:按顺序玩 `冒险一 古井` → `营地` → `冒险二 塔`。`角色/阿岚.md` 是冒险一结束时写出来的(示例里放了一份,直接玩营地也行)。

## 练习

1. 在营地加一个"铁匠":花 3 金币把短剑换成战斧(`take(sword, 1)`、`give(axe, 1)`、`equip(axe)`)。
2. 给 `levels.at` 加第 4 级,在冒险二里打赢石像后检查 `level_up_ready()`,能升就当场升。
3. 让冒险二的开头读出阿岚的天赋:`{inv ? brave: …}`。
